# Пхукет · дни у моря

Готовый статический сайт на русском: 28 ноября — 9 декабря 2026, The Marin Phuket. Сборка, зависимости, ключи API и аккаунты сервисов не нужны.

## Посмотреть

Откройте `index.html` в браузере. Для карточек нужен JavaScript. CSS, JS и иллюстрация работают локально; внешним картам и источникам нужен интернет. Текстовая версия — `PLAN.md`.

## Опубликовать на GitHub Pages

1. Создайте репозиторий на GitHub (для обычного бесплатного Pages — публичный).
2. Загрузите **содержимое** папки `phuket-plan` в корень репозитория: `index.html`, `styles.css`, `app.js`, `.nojekyll`, `README.md`, `PLAN.md`. Не загружайте только ZIP.
3. Зафиксируйте файлы в ветке `main`.
4. Откройте **Settings → Pages → Build and deployment**.
5. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь успешного Pages deployment во вкладке Actions. Адрес обычно `https://USERNAME.github.io/REPOSITORY/`; точный URL появится в Settings → Pages.

Все пути относительные: сайт поддерживает публикацию в подпапке репозитория. Домен и серверная часть не требуются. Репозиторий сайта: https://github.com/Anatoly-t/vacation. Публикация доступна после включения GitHub Pages в настройках репозитория.

Инструкция сверена с [документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что работает

- 12 компактных карточек-ссылок, раскрывающих соответствующий день.
- Подробные расписания, карты, оценки переездов, транспорт и примечания.
- Переключатель Пхи-Пхи / Симиланы меняет 1 декабря в обзоре и расписании. Выбор хранится только в браузере; у нового посетителя исходный вариант Пхи-Пхи. Это не бронирование.
- Раскрытие и сворачивание всех дней, печать / сохранение PDF через диалог браузера. При печати детали раскрываются, после закрытия диалога восстанавливаются.
- Клавиатурное управление, видимый фокус, адаптивная сетка, уменьшение анимаций по системной настройке.
- 29 ноября содержит только дату и название «День рождения»; раскрывающегося содержимого нет.

## Редактирование

Расписания — массив `days` и объект `similan` в `app.js`. Тексты сравнения, источников, шапки — `index.html`. Цвета и оформление — `styles.css`. После изменений обновите `PLAN.md` при необходимости. Не помещайте в публичный репозиторий паспортные данные, номера брони и билеты.

## Точность и источники

Проверка открытых источников: 17 ноября 2026. Ссылки и границы подтверждения показаны на сайте. Часы экскурсий — примеры опубликованных программ, расстояния и трансферы — планировочные оценки, не живые данные карт. Нет подтверждённых броней, проверки наличия мест или прогноза моря на даты поездки. Доступ к Большому Будде, работа рынка и морские выезды требуют повторной проверки перед посещением.

Иллюстрация моря выполнена средствами CSS специально для сайта. Внешних шрифтов, фотографий, аналитики и отслеживания нет.

Мобильная версия встроена: на телефоне блоки перестраиваются в одну колонку, обзор дней — в 2–3 колонки, кнопки и ссылки на карты имеют удобную область нажатия. Отдельного мобильного адреса не требуется.
